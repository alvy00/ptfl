# Alvy — Developer Portfolio

Interactive developer portfolio built with TanStack Start, React, and Vite. Career timeline visualized as a Git commit graph.

## Prerequisites

- [Bun](https://bun.sh/) (this project's package manager)

Do **not** use `npm install` — it will create a conflicting `package-lock.json`. Use Bun commands below.

## Setup

```bash
bun install
```

## Development

```bash
bun run dev
```

## Other scripts

| Command | Description |
| --- | --- |
| `bun run build` | Production build |
| `bun run build:dev` | Development-mode build |
| `bun run preview` | Preview production build |
| `bun run lint` | Run ESLint |
| `bun run format` | Format with Prettier |

## Package manager

This repo uses **Bun** (`bun.lock`). Install dependencies with `bun install` only.
